Penilaian Kelayakan Pinjaman

Repositori ini berisi implementasi program Python sederhana untuk menentukan kelayakan pengajuan pinjaman nasabah.

- Checking riwayat kredit nasabah.
- Validasi syarat pendapatan minimum.
- Evaluasi batas maksimal rasio pinjaman.

- `app.py`: Kode program utama Python.
- `index.html`: Tampilan antarmuka website sederhana.
- `README.md`: Dokumentasi dan penjelasan proyek.
